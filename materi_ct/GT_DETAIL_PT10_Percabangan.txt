PENJELASAN DETAIL:

A. STRUKTUR KONTROL

Default eksekusi algoritme: sekuensial (urut dari atas ke bawah).
Struktur kontrol mengubah urutan pengerjaan untuk mencapai tujuan algoritme.

Dua jenis struktur kontrol:
1. Percabangan (Conditionals): memilih instruksi berdasarkan kondisi
2. Perulangan (Loop): mengulang instruksi sampai kondisi terpenuhi

B. PERCABANGAN — KONDISI

Kondisi = ekspresi yang bernilai True atau False.
Sumber kondisi:
- Operasi relasional: x >= 3, a == b, y != 0
- Operasi logika: (1 < x) AND (x <= 5), NOT (a == b)

C. BENTUK-BENTUK PERCABANGAN

1. IF-THEN (satu arah):
   if (kondisi) then
     instruksi
   → Instruksi hanya dijalankan jika kondisi True.
   → Jika False, langsung ke baris berikutnya.

   Contoh:
   if (cloudy) then
     Bring umbrella

2. IF-THEN-ELSE (dua arah):
   if (kondisi) then
     instruksi-1
   else
     instruksi-2
   → Instruksi-1 jika True, instruksi-2 jika False. Salah satu PASTI dijalankan.

   Contoh:
   if (temp > 20) then
     Wear Shirt
   else
     Wear Sweater

3. PERCABANGAN BERSARANG BIASA (nested):
   if (kondisi-1) then
     if (kondisi-2) then
       instruksi-1
     else
       instruksi-2
   else
     instruksi-3

4. PERCABANGAN BERSARANG SEKUENSIAL (else-if):
   if (kondisi-1) then
     instruksi-1
   else if (kondisi-2) then
     instruksi-2
   else if (kondisi-3) then
     instruksi-3
   else
     instruksi-default

D. CONTOH DARI SLIDE

Maks 2 Bilangan:
  read(a, b)
  if (a > b) then print(a)
  else print(b)

Selisih 2 Bilangan (non-negatif):
  read(a, b)
  if (a > b) then selisih = a - b
  else selisih = b - a
  print(selisih)

Maks 3 Bilangan (else-if):
  read(a, b, c)
  if (a >= b and a >= c) then print(a)
  else if (b >= c and b >= a) then print(b)
  else print(c)

Paritas (ganjil/genap):
  read(a)
  sisa = a mod 2
  if (sisa == 0) then print("genap")
  else print("ganjil")

Huruf Mutu:
  Batas: A>=80, B>=70, C>=55, D>=40, E<40
  read(nilai)
  if (nilai >= 80) then print("A")
  else if (nilai >= 70) then print("B")
  else if (nilai >= 55) then print("C")
  else if (nilai >= 40) then print("D")
  else print("E")
