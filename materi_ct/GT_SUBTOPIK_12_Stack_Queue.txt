KONSEP INTI:

STACK (Tumpukan):
  Prinsip : LIFO -- Last In First Out
  Operasi : PUSH (tambah ke atas), POP (ambil dari atas)
  Analogi : tumpukan piring, Ctrl+Z, browser back

QUEUE (Antrian):
  Prinsip : FIFO -- First In First Out
  Operasi : ENQUEUE (tambah ke belakang), DEQUEUE (ambil dari depan)
  Analogi : antrian loket, printer queue, buffer jaringan

PEMILIHAN:
  LIFO diperlukan -> STACK
  FIFO diperlukan -> QUEUE
  Hierarkis      -> TREE
  Relasi kompleks -> GRAPH

IMPLEMENTASI STACK dengan Array:
  top = 0  // indeks elemen teratas (0 = kosong)
  function push(x):
    top = top + 1
    stack[top] = x
  function pop():
    if top == 0 then ERROR (stack kosong)
    nilai = stack[top]
    top = top - 1
    return nilai
  function peek():
    return stack[top]  // lihat atas tanpa pop

IMPLEMENTASI QUEUE dengan Array Sirkular:
  front = 0, rear = 0  // kosong jika front == rear
  function enqueue(x):
    rear = (rear + 1) mod kapasitas
    queue[rear] = x
  function dequeue():
    front = (front + 1) mod kapasitas
    return queue[front]

[SOAL 1 -- Simulasi Stack Dasar]
Mulai dari stack kosong, jalankan operasi berikut dan tentukan output:
push(5) -> push(7) -> push(2) -> pop -> push(6) -> push(9) ->
push(6) -> pop -> pop -> pop

JAWABAN:
push(5): stack=[5]
push(7): stack=[5,7]
push(2): stack=[5,7,2]
pop    : output=2, stack=[5,7]
push(6): stack=[5,7,6]
push(9): stack=[5,7,6,9]
push(6): stack=[5,7,6,9,6]
pop    : output=6, stack=[5,7,6,9]
pop    : output=9, stack=[5,7,6]
pop    : output=6, stack=[5,7]

Urutan output pop: 2, 6, 9, 6
Stack akhir: [5,7] (5 di bawah, 7 di atas)

[SOAL 2 -- Simulasi Queue Dasar]
Mulai dari queue kosong, jalankan dan tentukan output:
enqueue(A) -> enqueue(B) -> enqueue(C) -> dequeue ->
enqueue(D) -> enqueue(E) -> dequeue -> dequeue -> enqueue(F) -> dequeue

JAWABAN:
enqueue(A): queue=[A]
enqueue(B): queue=[A,B]
enqueue(C): queue=[A,B,C]
dequeue   : output=A, queue=[B,C]
enqueue(D): queue=[B,C,D]
enqueue(E): queue=[B,C,D,E]
dequeue   : output=B, queue=[C,D,E]
dequeue   : output=C, queue=[D,E]
enqueue(F): queue=[D,E,F]
dequeue   : output=D, queue=[E,F]

Urutan output dequeue: A, B, C, D
Queue akhir: [E,F] (E di depan, F di belakang)

[SOAL 4 -- Validasi Kurung dengan Stack]
Validasi apakah string kurung berikut seimbang:
a) "{([])<>()}"
b) "(()"
c) "{[}]"
d) "((()))"

ALGORITME:
  for setiap karakter c:
    if c adalah kurung buka: push(c)
    if c adalah kurung tutup:
      if stack kosong: return TIDAK VALID
      ambil = pop()
      if ambil tidak pasangan c: return TIDAK VALID
  if stack kosong: return VALID
  else: return TIDAK VALID

JAWABAN:
a) "{([])<>()}":
   push {, push (, push [, ] pop [ (cocok), ) pop ( (cocok),
   push <, > pop < (cocok), push (, ) pop ( (cocok), } pop { (cocok)
   Stack kosong -> VALID

b) "(()":
   push (, push (, ) pop ( (cocok), EOF -> stack=[(] tidak kosong
   -> TIDAK VALID

c) "{[}]":
   push {, push [, } -> pop [ -> [ tidak pasangan } -> TIDAK VALID

d) "((()))":
   push(, push(, push(, ) pop( cocok, ) pop( cocok, ) pop( cocok
   Stack kosong -> VALID

[SOAL 5 -- Pemilihan Struktur Data]
Tentukan struktur data yang paling tepat dan berikan alasan!

a) Server komputer melayani banyak request sesuai urutan masuknya.
b) Fitur undo/redo pada aplikasi desain grafis.
c) Sistem antrian tiket konser online.
d) Compiler memeriksa keseimbangan kurung dalam kode program.
e) Browser menyimpan history halaman yang dikunjungi untuk tombol back.
f) Playlist musik yang diputar dari awal ke akhir secara berurutan.

JAWABAN:
a) QUEUE (FIFO): request yang datang lebih awal dilayani lebih dahulu.
b) STACK (LIFO): setiap aksi di-push; undo men-pop aksi terakhir.
c) QUEUE (FIFO): pembeli yang mendaftar lebih awal mendapat tiket lebih dulu.
d) STACK (LIFO): kurung buka di-push; kurung tutup men-pop dan cek pasangan.
e) STACK (LIFO): halaman terakhir dikunjungi adalah yang pertama kembali saat back.
f) QUEUE (FIFO): lagu diputar sesuai urutan dimasukkan ke playlist.

[SOAL 6 -- Stack untuk Evaluasi Ekspresi Postfix]
Ekspresi postfix (Reverse Polish Notation): operand dulu, lalu operator.
Contoh: "3 4 + 5 *" berarti (3+4)*5 = 35

Algoritme evaluasi postfix:
  for setiap token t:
    if t adalah angka: push(t)
    if t adalah operator:
      b = pop()
      a = pop()
      push(a operator b)
  hasil = pop()

Evaluasi: "5 1 2 + 4 * + 3 -"

JAWABAN:
5: push(5), stack=[5]
1: push(1), stack=[5,1]
2: push(2), stack=[5,1,2]
+: b=2,a=1, push(1+2=3), stack=[5,3]
4: push(4), stack=[5,3,4]
*: b=4,a=3, push(3*4=12), stack=[5,12]
+: b=12,a=5, push(5+12=17), stack=[17]
3: push(3), stack=[17,3]
-: b=3,a=17, push(17-3=14), stack=[14]
Hasil = 14

Verifikasi: 5 + (1+2)*4 - 3 = 5 + 12 - 3 = 14 (benar!)

[SOAL 7 -- Queue: Simulasi Printer]
Printer menerima antrian dokumen. Waktu cetak setiap dokumen adalah 1 menit.
Waktu 0: D1(masuk), D2(masuk), D3(masuk)
Waktu 1: D1 mulai dicetak. D4(masuk)
Waktu 2: D1 selesai, D2 mulai. D5(masuk), D6(masuk)
Waktu 3: D2 selesai, D3 mulai.
Waktu 4: D3 selesai, D4 mulai.
Waktu 5: D4 selesai, D5 mulai.
...
Kapan D6 selesai dicetak?

JAWABAN:
Urutan masuk queue: D1, D2, D3, D4, D5, D6
Urutan selesai cetak (FIFO):
  Waktu 2: D1 selesai
  Waktu 3: D2 selesai
  Waktu 4: D3 selesai
  Waktu 5: D4 selesai
  Waktu 6: D5 selesai
  Waktu 7: D6 selesai

D6 selesai pada waktu 7.

[SOAL 8 -- Konversi Infix ke Postfix dengan Stack]
Konversikan "A + B * C" ke postfix!

Aturan:
  - Baca token kiri ke kanan
  - Operand langsung ke output
  - Operator: pop operator dari stack yang prioritasnya >= operator saat ini, lalu push
  - Prioritas: * / > + -

JAWABAN:
A: output=[A], stack=[]
+: stack=[+], output=[A]
B: output=[A,B], stack=[+]
*: prioritas * > +, jadi tidak pop. stack=[+,*], output=[A,B]
C: output=[A,B,C], stack=[+,*]
EOF: pop semua: output=[A,B,C,*,+]

Postfix: A B C * +
Verifikasi: A + (B*C) -> A B C * + (benar!)

[SOAL 9 -- Stack: Reverse dengan Stack]
Gunakan stack untuk membalik urutan elemen array [1,2,3,4,5]!

JAWABAN:
Langkah 1: Push semua elemen ke stack
  push(1),push(2),push(3),push(4),push(5)
  Stack (atas ke bawah): [5,4,3,2,1]

Langkah 2: Pop semua elemen ke array baru
  pop->5, pop->4, pop->3, pop->2, pop->1
  Array baru: [5,4,3,2,1]

Pseudocode:
  // Push semua
  for i = 1 to n do push(arr[i])
  // Pop ke array baru
  for i = 1 to n do arr_baru[i] = pop()

[SOAL 10 -- Analisis Kasus Campuran]
Berikan situasi NYATA di mana Stack dan Queue digunakan BERSAMA dalam satu sistem!

JAWABAN:
Contoh: Sistem Pengiriman Paket Online

QUEUE digunakan untuk:
  - Antrian pesanan yang masuk (order queue)
  - Setiap pesanan baru di-enqueue, diproses FIFO

STACK digunakan untuk:
  - Riwayat perubahan status pesanan (untuk rollback/undo jika ada kesalahan input)
  - Jika admin salah mengubah status, bisa undo ke status sebelumnya

Contoh konkret:
  - Order masuk: Enqueue ke processing queue
  - Saat memproses Order#5: Push setiap perubahan status ke history stack
  - Jika terjadi kesalahan -> Pop dari history stack -> kembalikan ke status sebelumnya
  - Order berikutnya: Dequeue dari processing queue
