KONSEP INTI:
Rekursi = fungsi yang memanggil DIRINYA SENDIRI.
Setiap fungsi rekursif WAJIB memiliki:
  1. BASE CASE  : kondisi penghentian (tanpa ini = infinite recursion)
  2. RECURSIVE CASE : pemanggilan diri sendiri dengan input yang LEBIH KECIL

PRINSIP KERJA:
  f(n) = kombinasi f(n-1) dan operasi lain
         sampai mencapai f(base) yang langsung dikembalikan

REKURSI vs ITERASI:
  Rekursi  : elegan, mudah dipahami, tapi overhead memory (call stack)
  Iterasi  : lebih efisien memori, tapi bisa lebih panjang kodenya

CALL STACK:
Setiap pemanggilan rekursif menyimpan state di stack.
Terlalu dalam -> Stack Overflow!

[SOAL 1 -- Faktorial]
Hitung n! secara rekursif. Trace untuk n=4.

DEFINISI MATEMATIS:
  0! = 1 (base case)
  n! = n x (n-1)! untuk n > 0

JAWABAN:
  function faktorial(n: int) : int
    if (n == 0 or n == 1) then return 1
    else return n * faktorial(n - 1)

Trace faktorial(4):
  faktorial(4) = 4 * faktorial(3)
               = 4 * 3 * faktorial(2)
               = 4 * 3 * 2 * faktorial(1)
               = 4 * 3 * 2 * 1
               = 24

Call stack (push): f(4)->f(3)->f(2)->f(1)
Return (pop): 1->2->6->24

[SOAL 2 -- Fibonacci]
Hitung bilangan Fibonacci ke-n secara rekursif.
Fib(1)=1, Fib(2)=1, Fib(n)=Fib(n-1)+Fib(n-2)

JAWABAN:
  function fib(n: int) : int
    if (n <= 2) then return 1
    else return fib(n-1) + fib(n-2)

Trace fib(5):
  fib(5) = fib(4) + fib(3)
         = (fib(3)+fib(2)) + (fib(2)+fib(1))
         = ((fib(2)+fib(1))+1) + (1+1)
         = ((1+1)+1) + 2
         = 3 + 2 = 5

Masalah: fib rekursif menghitung ulang nilai yang sama BERKALI-KALI!
fib(5) memanggil fib(3) DUA KALI -> tidak efisien O(2^n)

Solusi (memoization):
  memo = {} // cache hasil
  function fibMemo(n: int) : int
    if n in memo then return memo[n]
    if (n <= 2) then return 1
    hasil = fibMemo(n-1) + fibMemo(n-2)
    memo[n] = hasil
    return hasil

[SOAL 3 -- Penjumlahan Deret Rekursif]
Hitung 1+2+3+...+n secara rekursif.

JAWABAN:
  function sumTo(n: int) : int
    if (n <= 0) then return 0
    else return n + sumTo(n - 1)

Trace sumTo(4):
  sumTo(4) = 4 + sumTo(3)
           = 4 + 3 + sumTo(2)
           = 4 + 3 + 2 + sumTo(1)
           = 4 + 3 + 2 + 1 + sumTo(0)
           = 4 + 3 + 2 + 1 + 0
           = 10

[SOAL 4 -- Perpangkatan]
Hitung a^n secara rekursif (n >= 0, integer).

JAWABAN NAIF O(n):
  function pangkat(a: int, n: int) : int
    if (n == 0) then return 1
    else return a * pangkat(a, n-1)

JAWABAN EFISIEN O(log n) - Fast Exponentiation:
  function pangkatCepat(a: int, n: int) : int
    if (n == 0) then return 1
    else if (n mod 2 == 0) then
      setengah = pangkatCepat(a, n/2)
      return setengah * setengah
    else
      return a * pangkatCepat(a, n-1)

Trace pangkatCepat(2, 8):
  n=8 (genap): setengah = pangkatCepat(2,4)
    n=4 (genap): setengah = pangkatCepat(2,2)
      n=2 (genap): setengah = pangkatCepat(2,1)
        n=1 (ganjil): return 2 * pangkatCepat(2,0) = 2*1 = 2
      return 2*2 = 4
    return 4*4 = 16
  return 16*16 = 256
Hanya 4 pemanggilan, bukan 8!

[SOAL 5 -- Reverse String Rekursif]
Balikkan string s secara rekursif!

JAWABAN:
  function reverse(s: string) : string
    if (panjang(s) <= 1) then return s
    else return reverse(substring(s, 2, panjang(s))) + s[1]

Trace reverse("ABCD"):
  reverse("ABCD") = reverse("BCD") + "A"
                  = (reverse("CD") + "B") + "A"
                  = ((reverse("D") + "C") + "B") + "A"
                  = (("D" + "C") + "B") + "A"
                  = "DCBA"

[SOAL 6 -- Binary Search Rekursif]
Cari nilai target di array terurut menggunakan binary search rekursif!

JAWABAN:
  function binarySearch(arr[], kiri: int, kanan: int, target: int) : int
    if (kiri > kanan) then return -1  // tidak ditemukan
    tengah = (kiri + kanan) / 2
    if (arr[tengah] == target) then return tengah
    else if (arr[tengah] < target) then
      return binarySearch(arr, tengah+1, kanan, target)
    else
      return binarySearch(arr, kiri, tengah-1, target)

Trace arr=[1,3,5,7,9,11,13], target=7, kiri=0, kanan=6:
  tengah=3, arr[3]=7==7 -> return 3 (ditemukan di indeks 3)

Trace arr=[1,3,5,7,9,11,13], target=6, kiri=0, kanan=6:
  tengah=3, arr[3]=7>6 -> binarySearch(arr,0,2,6)
    tengah=1, arr[1]=3<6 -> binarySearch(arr,2,2,6)
      tengah=2, arr[2]=5!=6, arr[2]<6 -> binarySearch(arr,3,2,6)
        kiri=3>kanan=2 -> return -1
  Tidak ditemukan: return -1

Kompleksitas: O(log n)

[SOAL 7 -- Tower of Hanoi]
3 tiang (A, B, C), n piringan di tiang A (terkecil di atas).
Pindahkan semua ke C menggunakan B sebagai tiang bantu.
Aturan: tidak boleh menaruh piringan besar di atas kecil.

JAWABAN:
  function hanoi(n: int, asal: string, tujuan: string, bantu: string)
    if (n == 1) then
      print("Pindahkan piringan 1 dari", asal, "ke", tujuan)
    else
      hanoi(n-1, asal, bantu, tujuan)   // pindah n-1 piringan ke bantu
      print("Pindahkan piringan", n, "dari", asal, "ke", tujuan)
      hanoi(n-1, bantu, tujuan, asal)   // pindah n-1 piringan ke tujuan

Trace hanoi(2, A, C, B):
  hanoi(1, A, B, C): "Pindah piringan 1 dari A ke B"
  "Pindah piringan 2 dari A ke C"
  hanoi(1, B, C, A): "Pindah piringan 1 dari B ke C"

Total langkah untuk n piringan: 2^n - 1

[SOAL 8 -- GCD (FPB) Rekursif]
Implementasi FPB Euclidean secara rekursif!

JAWABAN:
  function fpb(a: int, b: int) : int
    if (b == 0) then return a
    else return fpb(b, a mod b)

Trace fpb(48, 18):
  fpb(48, 18) = fpb(18, 48 mod 18) = fpb(18, 12)
  fpb(18, 12) = fpb(12, 18 mod 12) = fpb(12, 6)
  fpb(12, 6)  = fpb(6, 12 mod 6)  = fpb(6, 0)
  fpb(6, 0)   = 6  (base case: b=0)
  Jawaban: 6

[SOAL 9 -- Kompresi Gambar Biner Rekursif]
Implementasikan kompresi biner grid rekursif!
Jika semua=0 -> "0", semua=1 -> "1", lainnya bagi 4 dan rekursi.

JAWABAN:
  function kompres(grid[][], r: int, c: int, ukuran: int) : string
    // Cek homogenitas
    semua0 = true; semua1 = true
    for i = r to r+ukuran-1 do
      for j = c to c+ukuran-1 do
        if grid[i][j] != 0 then semua0 = false
        if grid[i][j] != 1 then semua1 = false
    if semua0 then return "0"
    if semua1 then return "1"
    // Bagi menjadi 4 sub-grid
    half = ukuran / 2
    q1 = kompres(grid, r, c, half)          // kiri atas
    q2 = kompres(grid, r, c+half, half)     // kanan atas
    q3 = kompres(grid, r+half, c+half, half)// kanan bawah
    q4 = kompres(grid, r+half, c, half)     // kiri bawah
    return "(" + q1 + q2 + q3 + q4 + ")"

[SOAL 10 -- Hitung Jumlah Digit Rekursif]
Hitung jumlah semua digit bilangan n secara rekursif!

JAWABAN:
  function jumlahDigit(n: int) : int
    if (n < 10) then return n
    else return (n mod 10) + jumlahDigit(n / 10)

Trace jumlahDigit(1234):
  = 4 + jumlahDigit(123)
  = 4 + 3 + jumlahDigit(12)
  = 4 + 3 + 2 + jumlahDigit(1)
  = 4 + 3 + 2 + 1 = 10
